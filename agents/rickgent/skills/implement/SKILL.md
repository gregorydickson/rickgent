name: implement
description: Write code for a single ticket following the 8-phase lifecycle.
---

When implementing a ticket:

1. Research the current state with file:line references.
2. Plan the approach from reviewed research.
3. Write the code, staying within declared paths only.
4. Verify against acceptance criteria.
5. Commit with a clear message.
6. Do not claim done without a real commit — the completion oracle verifies git tree-truth.
