# Retained reliability proof contract

The canonical retained authority is
`artifacts/reliability/release-proof-index.json`; its declarative public matrix
is `artifacts/reliability/claim-surface-inventory.json`.

The index binds exact t37 packed-receipt and final t38 vertical-receipt bytes,
logical digests, sidecars, receipt schemas, release and build identities, npm
and wheel archive and inventory digests, redaction and canonicalization
versions, all named corpora, accepted preflight, clear diagnostics, two
independent crash/resume runs, authenticated live evidence, the exact proved
provider pair, delivery OID equality, and aggregate/per-run cleanup. Missing,
stale, malformed, mismatched, fixture, one-run, incomplete-lifecycle,
cleanup-failed, secret-bearing, or tampered evidence fails closed.

The installed proof profile restores only `resume_retry`,
`cross_vendor_review` for Codex CLI/OpenAI/gpt-5.6-sol plus Claude
Code/Anthropic/claude-opus-4-8[1m], and `automatic_delivery` for the observed
allowlisted disposable remote. The local t29 profile alone authorizes
reconciliation from persisted receipts and the lifecycle oracle.
`parallel_dispatch` and `raw_shell` remain unavailable.

Help, version, and doctor stay read-only and available under evidence
contraction. Protected mutation fails before state or side effects with the
stable diagnostic `RICKGENT_CAPABILITY_CONTRACTED: installed proof root did
not validate`.

`ready_for_delivery=local_oracle_complete` is local readiness, not delivery.
`delivered=remote_delivery_verified` requires independent remote branch and
PR-head equality with the delivery OID. `Done` is a delivered-only alias.

The hosted scope is one t38 disposable GitHub repository. The platform scope is
one t38 reference-platform observation. Neither is a general hosted-service,
provider, Darwin, Linux, or cross-platform support claim.

The declared `artifacts/reliability/recovery-parity-summary.json` authority is
absent and remains an explicit fail-closed discrepancy. The actual t29
crash-matrix manifest, fault-point corpus, recovery-parity test, and completion
commit are named directly; no missing artifact is invented or substituted.
